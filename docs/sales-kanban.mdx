# 💼 Pipeline Kanban Ventas

El tablero Kanban permite hacer seguimiento visual del estado de cada prospecto:

- **NUEVO:** Prospecto recién ingresado desde la web o BDC.
- **CONTACTADO:** Primera interacción efectuada por el vendedor.
- **TEST DRIVE AGENDADO:** Prueba de manejo programada en agenda.
- **NEGOCIACIÓN:** Propuesta económica emitida y estudio F&I enviado.
- **RESERVADO:** Pie de reserva recibido y auto bloqueado en stock.
- **CERRADO GANADO / PERDIDO:** Cierre de venta o registro de motivo de pérdida.
