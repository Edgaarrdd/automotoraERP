# 🏆 API Liquidación de Comisiones

### `GET /api/commissions/summary`
Obtiene el desglose de comisiones mensuales acumuladas por cada vendedor.

---

### `PATCH /api/commissions/{vendedor_id}/status`
Permite a Gerencia o Admin actualizar el estado de pago de las comisiones (`APROBADA`, `PAGADA`, `PENDIENTE_REVISION`).
