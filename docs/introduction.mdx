# 🚗 CRM Automotora ERP

**CRM Automotora ERP** es una solución enterprise desacoplada diseñada para digitalizar, automatizar y gestionar el ciclo de vida completo de la venta automotriz.

<CardGroup cols={2}>
  <Card title="Inventario & Decodificación Patentes" icon="car">
    Ingreso automatizado de vehículos con decodificación de patentes Registro Civil / Autofact e historial legal.
  </Card>
  <Card title="Pipeline Kanban Ventas" icon="kanban">
    Gestión visual del embudo de ventas con control de motivos de pérdida y lead score.
  </Card>
  <Card title="Cotizador & PDF Imprimible" icon="file-pdf">
    Simulación de crédito convencional y Crédito Inteligente (VFG) con impresión corporativa instantánea.
  </Card>
  <Card title="Agenda & Test Drives" icon="calendar">
    Agendamiento de pruebas de manejo, entregas de autos y reuniones comerciales por vendedor.
  </Card>
  <Card title="Portal del Consignatario" icon="eye">
    Transparencia en tiempo real para clientes que dejan vehículos en consignación.
  </Card>
  <Card title="Comisiones & Liquidaciones" icon="award">
    Cálculo automático de comisiones base (1.5%), bonos F&I y aprobación gerencial de pago.
  </Card>

## 🛠️ Stack Tecnológico

| Componente | Tecnología | Descripción |
| :--- | :--- | :--- |
| **Backend** | FastAPI + Python 3.14 | API REST asíncrona de alto rendimiento |
| **Frontend** | React 18 + Vite | SPA con UI Glassmorphism responsiva |
| **Styling** | Tailwind CSS | Sistema de diseño moderno y temas oscuros |
| **Base de Datos** | SQLite / PostgreSQL | Persistencia multi-tenant aislada mediante SQLAlchemy ORM |
| **Seguridad** | OAuth2 + JWT + Bcrypt | Control de acceso basado en 8 roles (RBAC) |
