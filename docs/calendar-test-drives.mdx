# 📅 Agenda & Test Drives (CU 2.2)

Permite organizar las actividades comerciales del equipo de ventas y BDC:

- **🚗 Test Drive:** Prueba de ruta con asignación de vehículo en stock.
- **🔑 Entrega de Auto:** Entrega oficial de vehículo vendido al cliente.
- **💼 Reunión Negociación:** Cita presencial para cierre de cotización o firma F&I.
- **🔧 PDI Taller:** Preparación técnica pre-entrega.
