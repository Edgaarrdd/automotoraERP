# 📄 API Cotizaciones

### `POST /api/quotes/`
Crea una nueva cotización financiera.

---

### `GET /api/quotes/{quote_id}/pdf-html`
Renderiza la plantilla HTML/PDF oficial de la cotización para impresión directa.

**Ejemplo de Petición:**
```bash
curl -X GET "http://localhost:8000/api/quotes/COT-1234/pdf-html" \
     -H "Authorization: Bearer <TOKEN>"
```
