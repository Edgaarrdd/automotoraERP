# 🏆 Módulo de Liquidación de Comisiones (CU 2.3)

Calcula de forma transparente la remuneración variable del equipo comercial.

- **Comisión Base:** 1.5% sobre las ventas totales ($CLP).
- **Bono F&I / Crédito:** $50.000 CLP adicionales por cada crédito pre-aprobado/colocado.
- **Aprobación de Pago:** Flujo con estado (`PENDIENTE`, `APROBADA`, `PAGADA`) gestionado por la Gerencia.
