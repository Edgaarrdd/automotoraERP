# 👁️ API Portal del Consignatario

### `GET /api/consignments/`
Obtiene la lista de autos consignados y su desglose de liquidación estimada al dueño.

---

### `GET /api/consignments/{vehicle_id}/summary`
Obtiene el informe consolidado de transparencia y la línea de tiempo del proceso de venta.
